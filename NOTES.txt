Implementation blueprint
Data ingestion — Use RecursiveCharacterTextSplitter from LangChain with chunk_size=512 and chunk_overlap=64 (roughly 10–20%). Feed chunks into BAAI/bge-large-en via sentence-transformers, then store vectors in ChromaDB for persistence or FAISS for pure-speed in-memory retrieval. For CPU-only machines, the smaller all-MiniLM-L6-v2 offers a good latency/quality trade-off.
Multi-layer caching — The key insight is the order of checks. Always hit the LLM response cache first (cheapest if it hits), then the vector search cache, then the embedding cache. Use cosine similarity ≥ 0.9 as the threshold to avoid stale cached answers for meaningfully different queries. Redis works well for all three layers; a simple Python dict works fine for prototyping.
Local LLM — llama-cpp-python with GGUF-quantized Mistral-7B-v0.3-Q4_K_M is the sweet spot for CPU machines. For GPU setups, load Llama-3-8B via transformers with 4-bit quantization using bitsandbytes. The system prompt should hard-instruct: (1) answer only from the provided context, (2) cite the document name/chunk ID, and (3) say "I don't know based on the provided documents" when context is insufficient.
Streaming — With llama-cpp-python set stream=True; with the transformers library use TextStreamer. This cuts perceived latency dramatically even when total generation time is the same.
Similarity threshold tuning — 0.9 is a safe starting point. If you're seeing stale cache hits, raise it to 0.92–0.95. If the cache rarely hits (queries vary a lot), consider lowering to 0.85 with a "freshness" TTL (e.g. invalidate after 24 hours) to balance coverage vs staleness.

One Thing to Watch — Cache Behaviour
After ingesting a new document, if you asked a similar question before, the old cached answer won't include the new document's content. Fix it with /clear:
Ask > /clear          ← wipe old cached answers
  ✓ All caches cleared.

Ask > What is this about?   ← now searches ALL documents fresh
Or force a one-time fresh answer without clearing everything:
python# In code — skip cache for one query
result = pipeline.ask(
    query      = "What is the new document about?",
    skip_cache = True,    ← bypasses LLM cache for this query only
)
